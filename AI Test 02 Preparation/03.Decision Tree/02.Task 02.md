What is Information Gain (IG)?

Information Gain measures how much an attribute reduces uncertainty (entropy) about the class.

In plain words:

“If I split the data using this attribute, how much more certain do I become about the class labels?”

The attribute with highest Information Gain is chosen in ID3.
