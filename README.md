# 🤖 Artificial Intelligence — Tasks

This repository contains my solutions to **programming tasks and exercises** completed as part of the **Artificial Intelligence** course.

The tasks focus on implementing and applying fundamental **Artificial Intelligence algorithms and problem-solving techniques** using **C++**.

## 📚 Topics

Throughout the tasks, the following concepts are covered:

- **Uninformed Search**
  - Breadth-First Search (BFS)
  - Depth-First Search (DFS)
  - Other basic search strategies

- **Informed Search**
  - Heuristic Search
  - Heuristic Functions
  - Distance Metrics
  - Manhattan Distance

- **Machine Learning**
  - K-Nearest Neighbors (KNN)
  - Classification

- **Problem Solving**
  - State-Space Search
  - Graph-Based Problems
  - Algorithmic Decision Making

## 🛠️ Technologies
